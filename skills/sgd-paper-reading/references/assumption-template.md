# 假设 / 引理讲解模板

用于讲解论文中的 Assumption(假设)或 Lemma(引理)。这是随机梯度理论论文里最容易被
初学者忽视、但实际上决定了整个证明能不能成立的部分——公式本身往往是套路化的代数操作,
真正的难点常常在于"为什么需要这条假设"。

## 1. 这条假设在约束什么(非正式但严格的陈述)

不用生活类比/比喻,直接用严格但非正式的语言说明:这条假设对哪个数学对象施加了什么限制,
以及这个限制带来的直接推论是什么。例如:
- L-光滑:梯度映射是 L-Lipschitz 的,即任意两点处梯度之差的范数不超过 L 乘以两点距离;
  直接推论是函数值可被二次上界控制(descent lemma),这是单步下降分析的起点。
- μ-强凸:f(x) - (μ/2)‖x‖² 仍是凸函数;直接推论是最优点唯一,且函数值与最优值之差
  可以被梯度范数的平方控制,从而能建立线性收敛。
- 有界方差:随机梯度与真实梯度之差的二阶矩不超过常数 σ²;直接推论是对噪声项取期望后,
  误差分析中只多出一个大小可控的 σ² 项。
- PL条件(Polyak-Łojasiewicz):‖∇f(x)‖² ≥ 2μ(f(x) - f*) 对所有 x 成立;由 μ-强凸可以推出
  PL条件但反之不然(PL 甚至不要求凸性);直接推论是"梯度范数小"就蕴含"函数值接近最优",
  因此很多强凸下的收敛率证明可以原样搬到 PL 条件下。

## 2. 用函数图像描述(文字描述,不需要真画图)

描述满足这条假设时函数大致长什么样、不满足时长什么样,帮助建立直觉图像。

## 3. 精确的数学定义

给出这条假设/引理的精确表述,逐个符号解释(参考公式模板里的符号表格形式)。

## 4. 去掉这条假设,证明会在哪里断掉

这是本模板最重要的一步。具体说明:如果没有这条假设,后续推导中的哪一步不等式会推不出来、
卡在哪个环节(比如"没有L-光滑性,就无法把 f(x_{t+1}) 用 f(x_t) 和梯度范数的平方项界住,
descent lemma 直接用不了")。

## 5. 正反例子

举一个满足这条假设的简单函数(比如 f(x) = x²),和一个不满足的反例(比如某个梯度会突变
或者是分段不连续的函数),帮助用户判断"什么时候能用这条假设"。

## 6. 溯源

如果这条假设/引理是引用自更早的经典文献(优化教材、更早的论文),用 web_search 确认最早出处,
说明本论文是直接沿用,还是做了修改(比如把强凸弱化成PL条件、把确定性梯度换成随机梯度版本)。

## 7. 判断题

给出3个具体的函数或场景,让用户判断哪些满足这条假设、哪些不满足,并给出理由。
