# 随机梯度类方法的细分方向速查表

讲解具体公式之前,先判断当前论文属于下面哪个(或哪几个交叉的)子方向,这样解释时用词才准确,
也能提醒用户"这个符号在不同子方向的论文里可能表示不同东西"。这不是要背下来的清单,
而是遇到对应内容时翻一下,确认自己没理解错方向。

## 1. 基础 SGD 与收敛性分析

- 核心更新式:x_{t+1} = x_t - η_t g_t,g_t 是随机梯度(通常满足 E[g_t|x_t] = ∇f(x_t))
- 常见结论形式:凸情形 O(1/√T),强凸情形 O(1/T),非凸情形常给"梯度范数平方的期望"收敛到0
  的速率(因为非凸问题一般不追求找到全局最优,只追求找到稳定点)
- 常见假设组合:L-光滑 + 有界方差(+ 凸/强凸/PL条件 之一)

## 2. 学习率 / 梯度衰减策略

- 关注点是学习率 η_t 如何随 t 变化(常数、1/t、1/√t、阶梯衰减、余弦衰减等)
- "梯度衰减"有时指学习率衰减,有时指梯度本身随迭代变小(比如接近最优点时梯度自然变小,
  这是结果不是人为设定的策略)——遇到这个词要先确认论文具体指哪一种,避免会错意
- 常见证明套路:把学习率衰减代入基础收敛不等式,对 t 求和,分析级数是否收敛/发散来确定最终速率

## 3. 动量与加速方法

- Heavy Ball / Polyak 动量:m_t = β m_{t-1} + g_t,x_{t+1} = x_t - η m_t
- Nesterov 加速梯度(NAG):在动量基础上"往前看一步"再算梯度,是"look-ahead"的思想
- 关注点通常是:动量能不能在保持随机性分析成立的前提下,把确定性情形下的加速效果带过来

## 4. 自适应学习率方法(Adagrad / RMSProp / Adam 系列)

- 核心思想:给每个坐标/参数分配不同的、随历史梯度信息自适应调整的学习率,
  而不是所有参数共用一个 η_t
- 符号上容易和"方差缩减"混淆的地方:这里的"二阶矩估计"v_t 是在估计梯度平方的滑动平均,
  不是在做无偏方差估计去"缩减"方差,目的不同(自适应调步长 vs 降低估计噪声)

## 5. 方差缩减方法(SVRG / SAGA / SARAH 等)

- 核心思想:随机梯度 g_t 本身噪声大,收敛慢;方差缩减方法构造一个新的估计量,
  仍然无偏但方差更小,常见做法是定期算一次全量梯度作为"锚点"再做修正
- 典型形式:g_t = ∇f_i(x_t) - ∇f_i(w) + ∇f(w),其中 w 是某个锚点、∇f(w) 是锚点处的全量梯度
- 关注点通常是证明方差随迭代趋于0,从而拿到比基础SGD更快的收敛率(比如从 O(1/√T) 提到线性收敛)

## 6. Mini-batch 与重要性采样

- Mini-batch:每步用 b 个样本的平均梯度而不是1个,方差通常按 1/b 缩小,
  但每步计算开销也相应变大,论文常讨论"batch size 和学习率如何联合调整"
- 重要性采样:不是均匀随机抽样本,而是按某种概率(比如梯度范数大小)偏向抽样,
  配合重要性权重保持无偏性,目的同样是降低方差

## 7. 分布式 / 联邦 / 去中心化 SGD

- 关注点变成"多个worker各自算梯度、如何聚合"这件事本身引入的额外误差来源,
  常见额外假设包括:worker间数据分布是否一致(i.i.d. vs non-i.i.d./异构)、
  通信是否有延迟/压缩(梯度压缩、量化、稀疏化引入的额外误差项)
- 符号上常见下标区分:i 表示第i个worker,t表示迭代轮次,两者容易搞混,读的时候要留意

## 8. 非凸优化中的收敛性刻画

- 非凸情形通常不谈"收敛到最优值",而是谈"收敛到一阶稳定点",
  常见的度量是 (1/T)·Σ E[‖∇f(x_t)‖²] 是不是随T增大趋于0、趋于0的速率是多少
- PL条件(Polyak-Łojasiewicz):非凸但比一般非凸更好分析的一类特殊情形,
  遇到"PL不等式""PL条件"字样时,提醒用户这是"弱化版的强凸",证明套路和强凸情形很像

## 使用建议

讲解具体公式时,如果论文明显属于上面某个子方向,在"公式的作用"和"在论文中的位置"这两部分
主动点出"这是在做xx方向常见的xx事情",帮用户把当前这一个公式和整个子领域的常见套路联系起来,
而不是孤立地讲这一个公式。
